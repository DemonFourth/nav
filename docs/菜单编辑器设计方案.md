- 右栏：固定 320px，flex 布局，flex-direction: column

## 2. 左栏 - 菜单结构

### 2.1 面板结构

| 区域 | 内容 |
|------|------|
| 面板头 | 标题"菜单结构" + "新增分类"按钮 |
| 拖拽提示 | `drag-hint` - 拖拽时显示位置提示文字 |
| 分类树 | 可滚动区域，显示树形结构 |

### 2.2 树节点内容

每个节点从左到右包含：
1. **展开/折叠箭头** - 仅当节点有子分类时显示
2. **拖拽手柄** - 6点图标，hover 时显示
3. **类型图标** - 根分类(横线) / 子分类(书本)
4. **分类名称**
5. **子分类数量徽章** - 显示 `children.length`
6. **移动按钮组** - [↑][↓] 两个按钮，始终显示

### 2.3 树节点状态

| 状态 | 视觉表现 |
|------|----------|
| 默认 | 白色背景 |
| Hover | 浅灰背景 (`bg-secondary`) |
| 选中 | 蓝色背景 + 蓝色边框 (`primary-100` + inset shadow) |
| 拖拽中 | 50% 透明度 |
| 拖拽目标-放置子分类 | 绿色边框 + 绿色背景 (`success`) |
| 拖拽目标-放置上方 | 上边蓝线指示 |
| 拖拽目标-放置下方 | 下边蓝线指示 |

### 2.4 树节点操作

| 操作 | 行为 |
|------|------|
| 点击节点 | 选中节点 + 右侧显示详情 |
| 点击展开箭头 | 切换展开/折叠状态 |
| 点击上移按钮 | 本地移动位置 + 记录 pending change |
| 点击下移按钮 | 本地移动位置 + 记录 pending change |
| 拖拽节点 | 拖拽到其他节点上方/下方/成为子分类 |

## 3. 右栏 - 分类详情

### 3.1 表单字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 分类名称 | 文本输入框 | 可编辑 |
| 父分类 | 下拉选择框 | 选项：根分类 / 其他分类（含路径） |
| 位置 | **只读文本** | 显示 "第 X / 共 Y 项" |
| 操作按钮 | 按钮组 | 重置 / 应用 |

### 3.2 表单行为

| 按钮 | 行为 |
|------|------|
| 重置 | 恢复表单为选中分类的原始数据（仅本地） |
| 应用 | 将表单数据应用到选中分类（仅本地，无 API 调用） |

### 3.3 危险区域

- 标题："危险区域"
- 按钮："删除此分类"（红色按钮）
- 提示文字：删除将同时删除所有子分类和书签

### 3.4 无选中状态

- 显示图标 + "选择左侧分类以编辑详情" 文字
- 居中显示

## 4. 对话框

### 4.1 新增分类对话框

| 元素 | 内容 |
|------|------|
| 标题 | 新增分类 |
| 字段1 | 分类名称 - 文本输入，回车提交 |
| 字段2 | 父分类 - 下拉选择（根分类 / 其他分类） |
| 底部按钮 | 取消 / 创建 |

### 4.2 删除确认对话框

| 元素 | 内容 |
|------|------|
| 标题 | 确认删除 |
| 内容 | 显示要删除的分类名称 + 警告信息（含子分类数量） |
| 底部按钮 | 取消 / 确认删除 |

### 4.3 保存确认对话框

| 元素 | 内容 |
|------|------|
| 标题 | 确认保存 |

| 变更类型 | create / rename / move / delete / reorder |
| 底部按钮 | 取消 / 确认保存 |

## 5. 待保存变更栏 (Pending Bar)

### 5.1 显示条件

- 仅当 `pendingChanges.length > 0` 时显示
- 固定在页面底部
- 显示时从下方滑入

### 5.2 内容

| 区域 | 内容 |
|------|------|
| 左侧 | 待保存数量按钮 + "查看详情"链接 |
| 右侧 | "放弃"按钮 |

### 5.3 行为

| 操作 | 行为 |
|------|------|
| 点击数量按钮 | 打开保存确认对话框 |
| 点击"查看详情" | 打开保存确认对话框 |
| 点击"放弃" | 清空 pendingChanges，恢复初始数据 |

## 6. 数据流设计

### 6.1 操作 → Pending Change 映射

| 操作 | 记录到 pendingChanges |
|------|----------------------|
| 新增分类 | `{ type: 'create', id, name, parentPath }` |
| 重命名 | `{ type: 'rename', id, oldName, newName }` |
| 移动分类 | `{ type: 'move', id, fromPath, toPath }` |
| 删除分类 | `{ type: 'delete', id, name, path }` |
| 上移/下移 | `{ type: 'reorder', id, fromPosition, toPosition }` |

### 6.2 待保存变更 → API 调用

点击"保存更改"按钮时：
```javascript
POST /api/reorder
Body: {
  type: 'categories',
  items: [ // 按顺序排列的所有分类
    { id: 'xxx', position: 1 },
    { id: 'yyy', position: 2 },
    ...
  ]
}
```

### 6.3 "应用"按钮行为

仅本地更新：
- 更新 `categories.value` 中对应分类的 `name`
- 更新 `categories.value` 中对应分类的 `parent_id`
- 更新 `formOriginal` 为当前表单值
- **无 API 调用**

## 9. 实现要点总结

### 9.1 需要修改的功能

1. **移除表单中的位置上下按钮**，改为只读文本显示 "第 X / 共 Y 项"
2. **"应用"按钮改为本地操作**，不调用 API
3. **`moveChildItem` 记录到 pendingChanges**，不调用 API
4. **添加 pending-bar 组件**，显示待保存变更数量
5. **点击保存时调用 `reorderItems('categories', items)`**
6. **"放弃"功能**：清空 pendingChanges，恢复数据

### 9.2 需要新增的组件/逻辑

| 组件 | 说明 |
|------|------|
| `pendingChanges` | ref 数组，存储待保存的变更 |
| `pending-bar` | 底部栏，显示变更数量和操作按钮 |
| 保存确认对话框 | 显示变更列表，供用户确认 |
| `confirmSave` | 调用 `reorderItems` API 批量保存 |
| `discardAll` | 清空 pendingChanges，恢复初始数据 |

### 9.3 文件变更

| 文件 | 变更内容 |
|------|----------|
| `useCategoryEditor.js` | 添加 `pendingChanges`、`confirmSave`、`discardAll` 等 |
| `NavSettingsModal.vue` | 添加 `pending-bar`、修改表单布局、调整按钮行为 |
| 可能新增样式文件 | 如果 pending-bar 样式复杂可单独提取 |

## 10. API 接口说明

### 10.1 已有 API

| 接口 | 方法 | 用途 |
|------|------|------|
| `POST /api/reorder` | 批量排序 | 接收 `{ type, items }` 批量更新分类顺序 |
| `PUT /api/categories/:id` | 更新分类 | 更新 name/parent（当前未用于排序） |

### 10.2 新增 API（如果需要）

| 接口 | 方法 | 用途 |
|------|------|------|
| `POST /api/categories` | 创建分类 | 新增分类（已有，验证即可） |
| `DELETE /api/categories/:id` | 删除分类 | 删除分类及其子分类（已有，验证即可） |
